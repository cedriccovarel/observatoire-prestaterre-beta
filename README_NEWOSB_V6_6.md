# Observatoire Prestaterre V6.6

Cette version corrige et complète la V6.5.

- Recherche réellement interactive dans les menus de filtres globaux et Exigences : saisie directe, filtrage instantané, sélection multiple des résultats visibles.
- Masquage explicite des options ne correspondant pas à la recherche, y compris sur GitHub Pages.
- Logo Prestaterre de la barre supérieure réduit pour ne plus déborder.
- Nom visible du site remplacé par **Observatoire Prestaterre**.
- Certification > Chronologie > Statut par année : « Non démarrée » est désormais strictement distinct de « Affaire perdue », « Affaire abandonnée » et « Affaire annulée ».
- Les affaires perdues / abandonnées / annulées sont affichables dans la chronologie mais restent hors des statistiques actives. Une case permet de les masquer.
- Cache-busting V6.6 appliqué aux ressources modifiées pour GitHub Pages.
