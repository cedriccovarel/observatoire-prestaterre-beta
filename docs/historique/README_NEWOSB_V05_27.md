# NEWOSB V05.27

## Cartographie — libellés de villes adaptatifs

- Réduction nette de la taille des noms de villes sur les fonds Historique, IGN et OSM.
- Taille des libellés recalculée selon le niveau de zoom afin d'éviter qu'ils grossissent avec la carte.
- Les grandes villes restent légèrement plus visibles que les autres communes, sans dominer la carte.
- Les métadonnées sous les villes (population / zone / nombre d'opérations) sont masquées aux zooms intermédiaires et n'apparaissent qu'aux niveaux de détail élevés.
- Contour blanc autour des textes allégé pour réduire l'effet visuel massif.
- Aucun changement du pont Apps Script OPERATIONS.
