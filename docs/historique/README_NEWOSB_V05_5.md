# NEWOSB V05.5

## Navigation cartographique

La carte Territoires dispose maintenant de commandes de navigation natives :

- boutons `+` et `-` fixes en haut a droite de la carte ;
- zoom a la molette, centre sur la position du pointeur ;
- deplacement de la carte par maintien du clic droit puis glisser ;
- menu contextuel navigateur desactive uniquement sur la carte ;
- niveau de zoom affiche en pourcentage ;
- zoom conserve lors de l'activation/desactivation des couches et lors du changement de page ;
- limite de zoom : 100 % a 800 %.

Les clics gauches sur les regions, departements et marqueurs conservent le comportement de cross-filtering existant.
