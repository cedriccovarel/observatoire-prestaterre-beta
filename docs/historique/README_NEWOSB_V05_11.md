# NEWOSB V05.11

## Carte – choix du fond

La carte Territoires propose maintenant trois fonds explicites :

- **Historique** : fond vectoriel NEWOSB utilisé avant l’ajout des fonds cartographiques externes. Aucun serveur de tuiles requis.
- **IGN** : Plan IGN.
- **OSM** : fond OpenStreetMap (avec fallback entre fournisseurs configurés).

Le choix du fond ne modifie pas les couches analytiques : zonage 1/2/3, régions, départements, EPCI, villes et opérations restent disponibles.
