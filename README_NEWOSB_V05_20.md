# NEWOSB V05.20

## Évolutions principales

### Vue d'ensemble — évolution des opérations
- Le graphique affiche désormais une courbe distincte pour chaque référentiel.
- Toutes les courbes partagent la même échelle verticale.
- La légende est visible sous le graphique.
- Un clic sur une année filtre l'année ; un clic sur un référentiel dans la légende filtre ce référentiel.

### Vue d'ensemble — chiffres clés
- Les 4 indicateurs Opérations / Logements / Bâtiments / Maîtres d'ouvrage sont maintenant envoyés ensemble vers une seule slide Présentation.
- Une seule icône Présentation est affichée pour le bloc complet.

### Exigences — graphiques à barres
- Chaque barre affiche l'effectif et son pourcentage dans le périmètre filtré correspondant.
- Les pourcentages se recalculent avec les filtres Exigences actifs.
- Les vues Top 5 restent inchangées.

## Compatibilité
- Le pont OPERATIONS est inchangé par rapport à V05.19.
- Aucun redéploiement de `Code_Operations.gs` n'est nécessaire.
