# NEWOSB V6.1 — branche de test Projet / Opération

- Projet = un Code interne unique.
- Plusieurs lignes ayant le même Code interne sont regroupées en un seul projet pour les statistiques générales.
- Opération technique = une ligne source du projet.
- Solutions constructives, énergie, carbone, DPE et Croiser les données exploitent les lignes techniques individuellement.
- Vue d’ensemble, territoires, acteurs, certification, labels/performances, Groupes MOA et totaux logements/bâtiments restent au niveau Projet.
- La fiche Projet indique le nombre d’opérations techniques rattachées.
